# بوت تليجرام مساعد ذكي يعمل بتقنية Gemini AI

هذا البوت هو مساعد ذكي لتليجرام مبني باستخدام Python، ويستفيد من واجهة برمجة تطبيقات Google Gemini (الطبقة المجانية) للمحادثات وتوليد الصور. يدعم البوت المحادثات باللغتين العربية والإنجليزية، ويحافظ على سجل المحادثات لكل مستخدم.

## الميزات

*   **محادثة ذكية**: يرد على الرسائل النصية باستخدام نماذج Gemini AI (مثل `gemini-3.5-flash`).
*   **توليد الصور**: ينشئ صورًا بناءً على وصف المستخدم باستخدام أمر `/image` (يعتمد على `gemini-2.5-flash-image`).
*   **سجل المحادثات**: يحافظ على سياق المحادثة لكل مستخدم.
*   **التعامل مع الأخطاء**: يتعامل مع الأخطاء بشكل سلس ويقدم رسائل توضيحية.
*   **دعم اللغات**: يدعم اللغتين العربية والإنجليزية في التفاعل.

## الأوامر

*   `/start`: يبدأ المحادثة ويعرض رسالة ترحيب.
*   `/help`: يعرض قائمة بالأوامر المتاحة.
*   `/image <وصف>`: لتوليد صورة بناءً على وصفك. مثال: `/image قطة تلعب بالكرة`.
*   `/clear`: لمسح سجل المحادثة الخاص بك والبدء من جديد.

## المتطلبات

*   حساب تليجرام.
*   توكن بوت تليجرام (يمكن الحصول عليه من BotFather).
*   مفتاح API لـ Google Gemini (يمكن الحصول عليه من Google AI Studio).
*   حساب Railway (للنشر).

## دليل النشر (Deployment Guide)

### 1. الحصول على توكن بوت تليجرام (Telegram Bot Token)

1.  افتح تطبيق تليجرام وابحث عن `@BotFather`.
2.  ابدأ محادثة معه واكتب `/newbot`.
3.  اتبع التعليمات لإعطاء اسم للبوت واسم مستخدم (يجب أن ينتهي بـ `bot`).
4.  سيزودك BotFather بـ **توكن API** الخاص بالبوت. احتفظ به بأمان، ستحتاجه لاحقًا.

### 2. الحصول على مفتاح Google Gemini API (GEMINI_API_KEY)

1.  انتقل إلى [Google AI Studio](https://aistudio.google.com/).
2.  سجل الدخول باستخدام حساب Google الخاص بك.
3.  انقر على `Get API key in Google AI Studio`.
4.  انقر على `Create API key in new project` أو `Create API key` إذا كان لديك مشروع موجود.
5.  انسخ المفتاح الذي تم إنشاؤه. هذا هو `GEMINI_API_KEY` الخاص بك.

### 3. إعداد المشروع محليًا (اختياري)

1.  استنسخ المستودع:
    ```bash
    git clone https://github.com/your-username/telegram-gemini-bot.git
    cd telegram-gemini-bot
    ```
2.  أنشئ بيئة افتراضية وقم بتنشيطها:
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```
3.  ثبت التبعيات:
    ```bash
    pip install -r requirements.txt
    ```
4.  أنشئ ملف `.env` في جذر المشروع وضع فيه مفاتيح API الخاصة بك:
    ```
    TELEGRAM_BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN_HERE
    GEMINI_API_KEY=YOUR_GEMINI_API_KEY_HERE
    ```
    تأكد من استبدال `YOUR_TELEGRAM_BOT_TOKEN_HERE` و `YOUR_GEMINI_API_KEY_HERE` بالتوكن والمفتاح الفعليين.
5.  شغل البوت:
    ```bash
    python bot.py
    ```

### 4. النشر على Railway

Railway هي منصة نشر سحابية سهلة الاستخدام. اتبع الخطوات التالية لنشر البوت الخاص بك:

1.  **إنشاء مستودع GitHub**: تأكد من أن كود البوت الخاص بك موجود في مستودع GitHub عام أو خاص. إذا لم يكن لديك، قم بإنشاء واحد وادفع الكود إليه.

2.  **تسجيل الدخول إلى Railway**: انتقل إلى [Railway.app](https://railway.app/) وسجل الدخول باستخدام حساب GitHub الخاص بك.

3.  **إنشاء مشروع جديد**: في لوحة تحكم Railway، انقر على `New Project` ثم `Deploy from GitHub Repo`.

4.  **ربط المستودع**: اختر المستودع الذي يحتوي على كود البوت الخاص بك.

5.  **إعداد المتغيرات البيئية**: بعد ربط المستودع، ستحتاج إلى إضافة المتغيرات البيئية (Environment Variables):
    *   انتقل إلى إعدادات مشروعك في Railway.
    *   ابحث عن قسم `Variables`.
    *   أضف المتغيرات التالية:
        *   `TELEGRAM_BOT_TOKEN`: الصق توكن بوت تليجرام الخاص بك هنا.
        *   `GEMINI_API_KEY`: الصق مفتاح Google Gemini API الخاص بك هنا.

6.  **تكوين النشر**: Railway سيكتشف تلقائيًا ملف `Procfile` و `requirements.txt` ويبدأ عملية النشر. إذا لم يبدأ تلقائيًا، يمكنك بدء النشر يدويًا.

7.  **مراقبة النشر**: يمكنك مراقبة سجلات النشر في لوحة تحكم Railway. بمجرد اكتمال النشر بنجاح، سيكون البوت الخاص بك جاهزًا للاستخدام على تليجرام.

## ملاحظات هامة

*   **أمان المفاتيح**: لا تشارك `TELEGRAM_BOT_TOKEN` أو `GEMINI_API_KEY` مع أي شخص. استخدم المتغيرات البيئية دائمًا للحفاظ على أمانها.
*   **استخدام Gemini API**: تأكد من مراجعة [شروط استخدام Google Gemini API](https://ai.google.dev/terms) لضمان الامتثال.
*   **حدود الاستخدام**: الطبقة المجانية من Gemini API لها حدود استخدام. قد تحتاج إلى الترقية إذا تجاوزت هذه الحدود.
